PDF to Word

Extract PDF text into an editable Word (.docx) document, processed locally.

This tool extracts the text content of your PDF into an editable Word document. It works best for text-based PDFs (reports, essays, letters). Scanned/image-only PDFs have no extractable text, and complex layouts, tables and images are not preserved — only the text.

Your Word document is ready.

Download .docx
This tool extracts text only; visual layout, tables and images are not preserved. For scanned/image-only PDFs, no text can be extracted.

How it works

Your PDF's text is extracted page-by-page using pdf.js's text layer (the same layer that lets you select text in a PDF viewer), then assembled into a real .docx Word document with one heading per page, using an open-source document-generation library. Only text is extracted — page layout, images, columns and tables are not reconstructed. Nothing is uploaded to a server.

Example

Upload a 4-page text report and download a Word document with 4 sections ("Page 1" through "Page 4"), each containing that page's text as editable paragraphs.

Frequently asked questions

Will my PDF's exact formatting (fonts, columns, images) be preserved?

No. This tool extracts text content only, so you'll need to reformat the document in Word if you need to match the original's exact visual layout.

What if my PDF is a scanned document?

Scanned PDFs are images, not text, so there's nothing to extract. This tool will tell you clearly if no text was found rather than producing an empty document.

Is this a real, editable Word file?

Yes — it's a genuine .docx file you can open and edit in Microsoft Word, Google Docs, or LibreOffice, not an image or a PDF renamed.
